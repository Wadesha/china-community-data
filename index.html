0这个专题在看什么

手里有一份小区清单:每行是一个小区,带着城市、区县、商圈、竣工年份、挂牌均价这些字段。这份清单看起来很简单,但每个字段背后都连着一套制度——规划体系、物业管理制度、不动产登记制度、行政区划制度、土地产权制度、交易监管制度。

这个专题不回答"现在房价多少""涨了还是跌了"——行情数字每个月都会失效,记录它意义有限。它回答的是一组不会过时的问题:

  • 小区到底是什么?它和楼盘、楼栋、户是什么关系?边界由谁划定?(§1)
  • 小区挂在哪里?省市县乡四级区划是什么?商圈为什么不是行政区划?(§2)
  • 挂牌均价是什么数字?它和成交价、网签价、评估价差在哪,怎么来的?(§3)
  • 竣工年份是什么?它和预售、交付怎么区分,和产权年限什么关系?(§4)
  • 小区里都是什么房?商品房、房改房、安置房、共有产权房……哪些会出现在这份清单里?(§5)
  • 每个字段怎么读?字段字典与口径边界。(§6)

先把体系立起来,任何一批数据(今天的、明年的、任何城市的)进来,都知道往哪个格子里放、按什么规则汇总、哪些结论能下、哪些不能。

1小区:它是什么

"小区"是个日常词,没有一部法律直接定义它。它实际上由三套制度共同塑造:规划制度给出空间形态,物业管理制度给出管理边界,不动产登记制度给出权属单元。房产平台上的"小区",是挂牌房源按名称和位置聚合出来的服务单元,最接近三者的交集。

1.1三重身份

身份依据边界怎么定在数据里的体现
规划单元《城市居住区规划设计标准》GB 50180-2018[1]按步行距离与人口规模划定生活圈层级决定小区的"正常规模"参照系(见 1.3)
物业区域《物业管理条例》及各省物业条例[3]以建设用地规划许可证红线图为基础,结合共用设施划定;一本许可证原则上一个区域[4]房产平台的小区边界≈物业区域:同一物业区域共用一套挂牌均价口径
登记单元《不动产登记暂行条例实施细则》[5]登记以"不动产单元"为基本单位——权属界线封闭且具有独立使用价值的空间;成套住房以套为单元[6]小区不是登记单元。登记链条是:宗地→幢→套,小区只是这些单元的空间聚类

一句话:规划管"该长多大",物业管"谁提供服务",登记管"谁拥有哪一套"。平台的小区清单,是以物业区域为主体、聚合其下所有"套"的挂牌行为形成的。

1.2楼盘 → 小区 → 栋 → 户

这四个词经常混用,但口径不同:楼盘/项目是开发商的开发口径(一块或几块出让宗地上的投资计划);小区是建成后的管理与生活单元;栋是建筑单体;户/套是权属与交易单元。四者不是一一对应:

情形说明
一个项目 → 一个小区最常见的整盘开发:统一规划、统一验收、一个物业区域
一个项目 → 多个小区大盘分期开发,各期之间被道路、河道分割,或配套设施可独立分割时,可分别划定物业区域[3];分期开发可分期验收[7],故同一大盘各"小区"竣工年份不同
多个项目 → 一个小区相邻不同主体开发的地块,若按整体规划设计范围划定为一个物业管理区域,则统一管理[4],平台可能合并展示
一个小区 → 多块宗地分期出让、分区拿地的常见结果;登记时按宗地分别办理
数据解读要点:同名"小区"在平台侧的边界以平台聚合规则为准,与规划、登记口径可能存在出入;大盘分期会使"一个小区"的竣工年份、价格跨度都很大。

1.3规模体系

GB 50180-2018 按步行尺度给出四级生活圈层级,居住街坊是最小单元[1][2]:

规划层级步行距离人口住宅套数与"小区"的对应
十五分钟生活圈居住区800–1000 m5–10 万人1.7–3.2 万套约等于一个街道办事处的辖区量级,含多个小区
十分钟生活圈居住区500 m1.5–2.5 万人5000–8000 套多个小区组成
五分钟生活圈居住区300 m0.5–1.2 万人1500–4000 套约 3–4 个居住街坊组成
居住街坊—1000–3000 人300–1000 套最接近单个普通小区(用地 2–4 公顷)

超出这个量级的"超级大盘"没有规划对应物,是市场化开发的产物。几个媒体与政府报道口径的例子[27][28]:

小区规模(报道口径,注意不同来源数字有出入)
贵阳花果园占地约 10 km²、总建筑面积约 1830 万 m²、常住人口近 40 万,内部再分 26 个区
北京天通苑占地约 8 km²、600 余栋、住户规模存在"约 6.9 万户"与"约 15 万户"两种统计口径
上海康城286 栋、规划约 1.25 万户、居住人口近 4 万

规模字段没有全国统一口径(规划户数/登记户数/社区治理口径/平台房源口径数字各不相同),引用任何"户数"都必须先问口径。

1.4命名体系

小区名不是随便起的。《地名管理条例》规定地名由专名 + 通名构成[9],各地对住宅区通名有明确规范:

规范来源要点
上海[10]居住区可用"城""家园"等;居住建筑可用园、苑、村、寓、庭、墅、舍、庐、居、邸、轩、筑、庄、阁、里、坊、院等;"花园/花苑"要求绿地率 50% 以上;"别墅/墅"须符合别墅建设条件
武汉[11]通名须符合实体规模与性质;禁用"宇宙、世界、环球、万国、全国、中华、中央"等夸大词;不得以帝王称谓、官衔作专名
九江[12]"中心"须用地 2 万 m² 以上或建面 10 万 m² 以上;"广场"须用地 1 万 m² 以上且含 3000 m² 以上室外公共活动场地

通名的传统语义与营销惯用理解(非全部由条例规定,属经验层):

通名传统含义 / 常见语境通名传统含义 / 常见语境
苑 / 园种植花草之地 → 普通住宅小区府官署、贵族宅邸 → 偏改善定位
城围合区域 → 大型社区湾水流弯曲处 → 滨水项目
里古代居民聚居处 → 邻里社区庄村庄、庄园 → 低密度、别墅类
庭 / 轩 / 阁庭院 / 长廊小屋 / 架空建筑 → 雅致、观景类华庭 / 公馆华丽庭院 / 官邸 → 高端定位
家属院 / 宿舍单位制时期的职工住房 → 老小区标志,通常房改房新村上世纪集中建设批次 → 房龄线索
数据解读要点:小区名是可结构化的信号——"家属院/宿舍/新村"指向 1998 年房改前的单位房,"品牌+府/湾/云筑"指向近年商品房开发,"花园/广场/中心"受命名规范约束可反推规模门槛。这是从名称字段提取信息的体系依据。

2.3商圈:市场发明的层

数据里的 Sub-district(商圈/板块)字段不是行政区划。它是房产平台和行业机构按商业资源、交通、居住形态、市场热度划出的市场概念:

  • 一个商圈可能覆盖一个街道,也可能跨多个街道甚至跨区;同一城市不同平台的划分互不一致(如广州板块,克而瑞划 62 个,另一数据源划 83 个)[15];
  • 常见切分逻辑:学区片(以学校服务范围)、地铁节点(以站点)、商业中心(以综合体)、规划概念区;
  • 数据中出现的"XX周边"(如"广州周边""珠海周边")是平台的外围聚合入口,连行政区划都不是,只能作弱参照。
数据解读要点:区县字段可以做严格的空间聚合(有民政部代码),商圈字段只能做同平台内部的相对比较,跨平台不可比。

2.4完整归属链

一个小区从产权到治理的完整空间归属(以西安市新城区陕汽万寿小区为例[18]):

省(陕西) → 地级市(西安) → 区县(新城区) → 街道(胡家庙街道,区县政府派出机关) → 社区居委会(陕汽社区,基层群众自治组织[17]) → 小区(陕汽万寿小区) → 栋 → 套

注意三个主体不是上下级,是分工:物业服务企业管小区内部设施与环境;社区居委会管居民自治与公共服务;街道办事处统筹辖区治理。数据里的小区只精确到"区县 + 商圈 + 道路"一级,街道与社区层信息需要地址解析才能还原。

3价格:这个数字是什么

3.1前置:土地制度

中国城市住宅的价格体系建立在一项土地制度上:城市土地国有,有偿、有限期使用。《城市房地产管理法》第三条确立了这一制度[19];住宅用地出让年限一般为 70 年,自出让日起算。《民法典》第 359 条规定住宅建设用地使用权期满自动续期,续期费用缴纳办法依法律、行政法规办理——即续期本身确定,费用规则尚未最终落地[20]。

由此区分两个经常被混淆的概念:房龄=当前年份 − 竣工年份,衡量建筑物新旧;土地剩余年限=70 −(当前年份 − 出让年份),衡量权利期限。出让通常早于竣工,所以同一年竣工的房子,剩余年限可以不同。二者都影响评估与贷款,但机制不同。

3.2七种价格

一宗二手房交易从头到尾会产生一串"价格",定义各不相同[23][24]:

价格谁定的是什么 / 什么场景
挂牌价卖方(经中介发布)业主委托出售的报价,是卖方要约的起点,通常高于最终成交
成交价买卖双方协商实际支付的合同价格,反映真实交易
网签价交易双方在房管部门系统备案填写网签合同上的价格,用于官方备案、贷款审批与税费核定;可能与实际成交价不同
评估价银行委托的第三方评估机构银行核定贷款额度的依据,通常偏保守;受房龄、户型、楼层、朝向、物业、地段影响
指导价 / 核验价地方政府部门交易管理与价格核验的基准;网签价明显低于基准的,按基准核定税费
计税价税务部门过户缴税时的计税基础,取网签价与计税评估价符合规则者
挂牌均价房产平台计算本数据的字段:小区内在售房源挂牌价的平均值,卖方报价的均值,不是任何一笔交易的价格

3.3本数据的口径

字段
Price(k) —— 小区挂牌均价(元/m²)
计算方式
平台收录的该小区在售房源挂牌价的平均
性质
卖方报价,非成交价;有效前提是该小区有在售房源
缺失形态
"暂无均价" —— 无在售挂牌房源或平台未计算,是缺失值而非 0
更新
随挂牌房源增删与调价变化,每次抓取是一个时间快照

两条统计纪律:其一,房价分布右偏、极值多,聚合时中位数比均值稳健,本专题一律用中位数;其二,挂牌价与成交价之间的差距没有固定比例,随城市、户型、挂牌时长变化,所以本专题只做挂牌体系内部的比较,不推断成交水平。

3.4交易流程中的价格

环节产生什么
挂牌 → 带看 → 议价挂牌价(起点)→ 意向成交价
定金 → 签约合同价格;定金锁定交易与违约责任
网签网签价(备案口径)
资金监管购房款进入监管账户,保障"钱房两空"风险[25]
贷款审批评估价 + 贷款成数 → 实际可贷额度
过户缴税计税价(税费基础)
交房成交价最终实现

可见"价格"在流程中是一个不断被修正的序列:挂牌价是第一个数,成交价是最后一个数,中间还有网签、评估、计税三个口径。平台数据停在第一个数。

4年份:竣工年份是什么

4.1三个时间点:预售 / 竣工 / 交付

时间点是什么判断依据
预售房子还没建好,取得预售许可后先卖预售许可证、购房合同(最早)
竣工建设工程竣工验收合格;建设单位须在竣工验收合格之日起 15 日内向建设主管部门备案[8]竣工验收合格之日(本字段口径,非备案完成日)
交付房屋移交给购房人;未完成竣工验收备案,购房人有权拒收交付通知与交接手续(通常在竣工之后)

4.2分期与"小区竣工年份"

群体开发项目实行分期开发的,可以分期验收[7]。因此平台标注的"竣工年份"可能是首期、末期或最近一期的竣工时间——没有全国统一口径。大盘的数据里同小区各期差出十几年的情况是正常的,年份字段只能读到"该小区建成于哪个年代"的粒度。

4.3房龄的金融含义(惯例,非法律)

  • 银行对房龄与贷款年限的组合有内部风控口径(如"房龄 + 贷款年限 ≤ 30/40 年"等说法),属各银行惯例而非法律规定,城市与产品之间不同;
  • 老房子评估价偏低的机制:房龄折旧 + 处置难度(接盘群体小、变现周期长)→ 银行保守评估,不是法定打折;
  • 1998 年房改是重要的结构性分界:此前以单位房(房改房)为主,此后商品房成为主体——年份字段因此同时携带"建筑年代"与"住房制度阶段"双重信息。

5房子:小区里都是什么房

同一张小区清单里,混着产权性质完全不同的房子[21][22]:

类型产权特征交易限制会否出现在小区库
商品房出让土地,完整产权无特殊限制会(主体)
房改房 / 已购公房划拨土地,职工按成本价/标准价购买上市通常需补缴土地出让金;标准价购房属部分产权会(老小区主体,如各类家属院)
央产房中央单位已购公房(房改房特殊类)需原产权单位/住房资金中心审核上市会
经济适用房政策优惠、限定面积与售价如广州:签合同满 5 年且取得权证方可申请上市会
限价商品房市场化商品住房,权属证书注明"限价"购房资格与转让受政策约束会
共有产权房政府与购房人按份共有如北京:取证未满 5 年不得转让(可由代持机构回购),满 5 年可按市场价转让份额会
安置房 / 回迁房拆迁补偿形成,产权视安置协议而定视登记性质与当地补缴规则会
人才住房面向特定群体的政策性住房持有年限、转让对象、政府回购等限制会
自建房多为集体土地上自建能否登记与交易视土地性质与历史审批部分
小产权房集体土地,无国家颁发的产权证书,合同不备案产权不受完整法律保护不应出现;出现即高风险条目
军产房军队系统管理房产多按军队内部程序办理,难以地方过户边缘出现
数据解读要点:清单只告诉我们"这是一个挂牌聚合单元",不告诉我们房子的产权类型。老小区大概率混着房改房与少量回迁房,新小区以商品房为主,但这只能作为概率判断。名字里的"家属院/宿舍"是房改房最可靠的文本信号(见 1.4)。

6字段字典

当前 schema 共 13 个字段,逐一定义与解读边界:

字段是什么解读注意
City 城市房产平台城市站点的归属城市≠严格行政区划:县级市可能独立建站;省直辖县级市无上级地级市;需另行建立城市→省映射
Name (a) 小区名平台收录的小区名称专名+通名结构(见 1.4);同城市重名小区需以区县/道路消歧
Year Built (b) 竣工年份竣工验收合格年份约 30–50% 缺失;分期开发下口径不一(见 4.2);缺失即缺失,不推算
District (c) 区县小区所属县级区划(市辖区/县/县级市/旗)可映射民政部区划代码做严格聚合;少数为"N/A"或简称
Sub-district (d) 商圈平台划分的商圈/板块市场概念,非行政区划,跨平台不可比(见 2.3)

7两个分析视图

框架立好后,专题一先落两个不依赖行情解读的结构性视图:

价格浏览器:省 → 市 → 区县逐级下钻:省 → 城市 → 区县,每级给出小区数、挂牌中位数、分位区间。层级即第 2 节的行政区划体系;所有城市→省的映射、区县→类型(市辖区/县/县级市)的标记都在这里体现。
年份 × 价格:城市级曲线按竣工年份分段(每 5 年)统计各城市挂牌中位数,观察"建成年代 → 报价水平"的结构关系。只统计有竣工年份的小区,缺失不插补;核心区老房的韧性(见 1.1/4.3)会在一线城市的曲线里显形。

两个视图当前均填充模拟数据(结构、字段、缺失形态对齐真实抓取),真实数据接入后无需改版。

8延伸:三部百科卷

专题一立的是数据框架。站点另有三条文本线,把"小区"放回更长的演变里:一部讲房子,一部讲制度,一部讲城乡可见的外观状态。三卷同一体例——以条目为基本单元,配技术档案(档 n-n)、图版(图 n-n)与编号引用(附录集中列来源),黑白灰、无图标;编号各卷独立,第三卷的"图 1-1"与前两卷的"图 1-1"互不相涉。

第一卷 · 中国居住建筑史回答"房子长什么样":从穴居干栏、里坊宅院到单元楼与商品房,六编四附录,按居住建筑自身形制的演变断代。与本专题的衔接点:§4 竣工年份与 §5 房型谱系——年份字段背后是一部完整的建造制度史,1998 年房改的断裂(见 4.3)在两卷里都有对应章节。
第二卷 · 中国城市规划与区域发展回答"城市怎么被组织起来":从营国制度、里坊街巷、近代市政、计划经济规划到国土空间规划,六编四附录,以规划权归属、编制依据、规划对象三项制度变量断代。与本专题的衔接点:§1 小区的空间形态与 §2 行政区划层级——小区是规划体系的最小落点,区县是规划编制的基本行政单元。
第三卷 · 中国近现代城乡风貌回答"眼前这块风貌是什么时候、被谁、按什么规则造出来的":起点即 1840,不写古代——今天城乡风貌的物质存量几乎全部形成于此后。以"建造主体 × 资金来源 × 规则依据"三变量整体换代分四期,城市与乡村双线并观;第六编与附录提供识别工具——从窗框、阳台、外饰面、单元门、楼梯间五个维度判定建筑年代,从街道界面判定片区年代。与本专题的衔接点:§4 竣工年份——年代鉴定特征总表即年份字段的肉眼版。

三卷均为自包含的纯文本,不随行情变化、不依赖 data 文件;数据视图替换真实数据时,三卷无需任何改动。

9口径与局限

局限处理方式
挂牌价 ≠ 成交价只做挂牌体系内部比较,不推断成交水平(见 3.3)
样本为站点头部样本多数城市采集的是平台默认排序前若干页,偏向活跃小区;统计结果代表"平台可见样本",不推及全市存量
多批次时间快照混合按 Fetch Date 分快照,聚合时注明;不同快照之间不做趋势推断
覆盖缺口部分城市因采集故障缺失或不足,发布时如实标注覆盖情况,不填补
城市归属错误风险历史批次存在城市错标,清洗规则:去导航垃圾行、以平台 URL 域名校验城市、同城同指纹去重
年份缺失与口径不一缺失即缺失,不插补;大盘分期导致的年份跨度如实保留
